# 현장 일정 날씨판

오늘 현장 일정과 지역별 날씨를 한 화면에서 보고, 날씨 때문에 주의 · 중지를 검토할 일정을 표시합니다. (교육용 가상 데이터)

## 여는 법
- 인터넷 : 배포 주소로 연다. (배포 후 Vercel 주소를 여기에 적기)
- 내 PC : `index.html`을 더블클릭해 열 수 있지만, 브라우저가 JSON 읽기를 막으면 '배포 주소로 열어 주세요'가 표시된다.

## 일정 데이터
- 기본 가상 일정은 `data/tasks.json`에서 먼저 읽는다.
- 화면에서 추가한 일정만 브라우저의 `localStorage` (`wx_added`)에 따로 저장하고 기본 일정 뒤에 표시한다.
- 브라우저 저장소를 지우면 추가 일정은 사라진다. 기본 JSON 파일은 바뀌지 않는다.

## 확인 방법
- T-01: 배포 주소에서 기본 일정 6건이 보이는지 확인한다.
- T-02: 일정을 추가하고 새로고침해도 기본 일정 뒤에 추가 일정이 남는지 확인한다. 개발자 도구의 `wx_added`에는 추가 일정만 있어야 한다.
- T-05: `data/tasks.json`의 기본 일정을 변경한 뒤 새로고침하면 변경한 기본 일정이 먼저, 기존 추가 일정이 뒤에 보이는지 확인한다.
- T-06: 더블클릭으로 열어 JSON 읽기가 차단되면 '배포 주소로 열어 주세요'가 표시되는지 확인한다.
